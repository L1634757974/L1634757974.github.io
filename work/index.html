中国华电科工集团
氢能展厅

从前期沟通、展厅布局与概念提案，到效果图渲染、平面设计及后续修改，主要由我承担，并持续参与制作与安装阶段的沟通。

01 / BRIEF & CONCEPT

将技术内容，
组织成空间叙事。

项目围绕氢能技术研发与产业应用展开，展示核心产品、关键材料、智能控制、示范项目及创新成果。方案以“氢动未来 · 智创绿色能源”为概念，连接技术展示、企业形象传播与参观体验。

我承担前期沟通、展厅布局与概念提案，将内容组织与空间表达放在同一套方案中推进。

02 / SPATIAL LANGUAGE

统一视觉语言，
让信息清晰呈现。

方案采用蓝白科技色彩，结合数字矩阵、线条与几何模块，使不同展示区域保持视觉上的连续性。参观动线串联各展示节点，展项围绕空间边界展开。

效果图渲染由我主要完成，用于呈现入口、主展示面及局部展项的空间关系，并支持后续方案修改。

03 / GRAPHIC DEVELOPMENT

从空间效果，
推进到平面深化。

在空间方案之外，我继续承担展厅平面设计与后续修改。8 月的校稿文件涵盖研发中心介绍、产品信息、产业链与示范项目等内容，进一步细化文字、图像和版式层级。

这一阶段将空间中的展示意图转化为具体的展面设计，让三维效果与平面内容形成衔接。

04 / BUDGET & EXECUTION

有限预算下，
平衡效果与工艺。

项目难点：客户预算较低，同时需要保证展厅的视觉效果，设计方案需要兼顾制作可行性与成本。

我的推进方式：与制作、安装同事详细沟通可行工艺，以尽量保留设计效果为前提控制预算，将工艺可行性纳入方案落地的判断。

落地跟进：墙面结构制作阶段，我曾到现场比对；最终安装阶段虽未到场，但一直保持线上沟通，持续参与项目推进。

05 / BUILT PROJECT

从设计方案，
到落地实景。

以下为展厅实际落地照片，展示入口、核心展区、示范项目展面与成果展示区域。蓝白色彩、发光线条、顶部造型及展面布局共同呈现最终空间效果，可与前面的设计效果图对照查看。

墙面结构制作阶段，我到现场进行比对；最终安装阶段通过线上沟通持续跟进。

06 / CONTRIBUTION & DELIVERABLES

从设计深化，持续跟进落地。

个人工作覆盖前期沟通、展厅布局、概念提案、效果图渲染、平面设计及后续修改，并包括与制作、安装同事的工艺沟通、墙面结构制作阶段的现场比对，以及最终安装阶段的线上跟进。

本案例结合设计提案、平面深化与落地实景，呈现从方案到实际空间的完整过程。

02 / FEATURED PROJECT2025 · 品牌与空间

中国人民公安大学
未来警务学院

从院徽设计到学院空间文化建设，独立完成设计工作；项目接入后，独立承担客户沟通、方案设计、修改及定稿推进。

我的角色独立设计 / 客户对接

01 / IDENTITY

从院徽出发，
建立学院的视觉识别。

我独立完成未来警务学院院徽设计，并将学院识别延伸到门头、入口及文化墙等应用中，使标志与空间表达形成联系。

院徽采用蓝白配色，以中心图形、环绕文字和圆形结构构成识别。后续空间视觉延续蓝色主调，结合几何边框与线性元素，建立统一的视觉表达。

02 / SPATIAL APPLICATION

让学院识别，
进入真实的空间。

设计范围从院徽延展至学院入口、门头与空间文化内容。入口视觉将院徽、学院名称、PPSUC 字样与校训组合，以蓝色几何造型形成清晰的视觉重心。

空间方案通过平面设计稿及不同视角的效果图呈现，帮助客户判断内容、造型与环境的关系，并作为沟通和修改的依据。

03 / CULTURAL SPACE

统一设计语言，
承载不同的文化内容。

围绕学院文化建设内容，独立完成文化墙、主题标语及楼梯沿线等设计。不同展面使用一致的蓝色边框、几何转折与线条元素，并按内容层级组织标题、正文和图形。

空间文化稿件在统一视觉风格下适配不同位置与画面比例，使院徽设计与整体环境保持连续。

04 / BUILT SIGNAGE

从门头方案，
到实体呈现。

已提供的门头实景记录了学院名称、院徽及蓝色几何造型在建筑入口的实际呈现，可与前面的门头设计稿对应查看。

本节为落地实景照片；前面的室内空间图片为设计效果图，文化墙图片为设计稿。

05 / OWNERSHIP & PROCESS

独立对接，推进至最终定稿。

项目接入后，由我持续独立对接客户，承担院徽和空间文化建设的方案设计、沟通修改及最终定稿。工作覆盖视觉识别与空间应用，保持设计思路在不同载体中的一致性。

这段经历体现了独立推进项目、整合品牌与空间视觉，以及持续沟通并推进定稿的能力。
